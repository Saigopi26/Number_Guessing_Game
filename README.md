# Number Guessing Game

## Project URL
Project Page URL = https://github.com/Saigopi26/Number_Guessing_Game

## Description
This is a simple Number Guessing Game implemented in Python.

The user has to guess a number between 1 and 100.
The game provides three difficulty levels with different chances.

## Difficulty Levels
Easy – 10 chances  
Medium – 5 chances  
Hard – 3 chances  

## How the Game Works
1. The user selects a difficulty level.
2. The program generates a random number between 1 and 100.
3. The user enters guesses within the given number of chances.
4. The program gives hints if the guess is higher or lower.
5. The game ends when the number is guessed correctly or chances are exhausted.

## Technologies Used
Python

## How to Run
1. Clone the repository.
2. Run the program using the command below.

python program.py
