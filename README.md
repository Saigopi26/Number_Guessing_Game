## Description
This project is a simple **Number Guessing Game** implemented in Python.

The user has to guess a number between **1 and 100**.  
The game provides **three difficulty levels** with different chances.

## Difficulty Levels
- **Easy** – 10 chances  
- **Medium** – 5 chances  
- **Hard** – 3 chances  

## How the Game Works
1. The user selects a difficulty level.
2. A random number between 1 and 100 is generated.
3. The user tries to guess the number within the allowed attempts.
4. Hints are given whether the guess is higher or lower.
5. The game ends when the number is guessed or attempts are exhausted.
